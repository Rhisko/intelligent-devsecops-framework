Immediate Actions

  1. Replace all uses of MD5 with SHA256 or stronger hash functions in app/crypto.py.
  2. Refactor eval() usage in app/payment.py to use safe parsing methods like ast.literal_eval().
  3. Update OpenSSL package in Dockerfile to fixed version 3.5.4-1~deb13u2 or later.
  4. Upgrade jaraco.context and other vulnerable dependencies in requirements.txt to secure versions.
  5. Modify Dockerfile to specify a non-root user with USER directive to avoid running container as root.
  6. Refactor SQL query construction in app/auth.py and app/db_data.py to use parameterized queries or ORM methods.
  7. Remove hardcoded secrets from app/db_data.py and app/request.py; use environment variables or secret management.
  8. Add timeout parameters to all requests calls in app/request.py to prevent indefinite hangs.
